# WorkFlow Hub

Enterprise Resource & Workflow Management Portal

## Overview

WorkFlow Hub is a full-stack enterprise web application built to centralize internal organizational workflows.

The system enables employees, managers, and administrators to manage daily operations through a secure web portal.

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- React Router
- Axios

### Backend
- FastAPI
- SQLAlchemy
- Alembic
- Pydantic

### Database
- PostgreSQL 17
